# Product Planning

This folder contains Product Owner planning artifacts for the MVP.

Use these folders for different planning levels:

- `requirements/`: product requirements, decisions, user journeys, and acceptance criteria.
- `epics/`: larger outcome-focused work packages that group related tasks.
- `tasks/`: small implementation-ready work items for backend, frontend, shared, or release work.

Keep documents short, testable, and tied to the MVP scope in `docs/product-mvp.md`.
