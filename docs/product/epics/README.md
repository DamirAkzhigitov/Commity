# Epics

Use this folder for larger MVP work packages that group related requirements and tasks.

Recommended file naming:

```text
EPIC-001-chat-core-loop.md
EPIC-002-local-first-data.md
EPIC-003-auth-billing-usage.md
```

Recommended structure:

```markdown
# EPIC-001: Epic Name

## Goal

## Why Now

## Included Requirements
- `REQ-...`

## Tasks
- `TASK-...`

## Done When
- [ ] ...

## Risks
```
